Modul i18n: katalog `id.json`/`en.json`, `t()`, dan format angka/tanggal.

Boleh mengimpor: `theme` (sesama modul dasar), `utils`, dan paket npm.
Dilarang mengimpor: `kit`, `components/ui`, `renderer`, `shell`, `api`, `stores`.
Dipakai lewat impor biasa oleh molekul ke atas; `stores` boleh memanggil `setLocale`.
